# 사용자 매뉴얼 화면 촬영 목록

캡처를 `docs/manual/captures/` 폴더에 **아래 파일명 그대로** 저장해 주세요.
매뉴얼 생성기가 이 파일명을 찾아 자동으로 넣습니다.

## 촬영 방법

| 항목 | 권장 |
| --- | --- |
| 주소 | `http://vitron-nas:8082` |
| 브라우저 창 | 최대화 (넓을수록 좋습니다) |
| 캡처 범위 | 아래 각 항목의 「범위」대로 |
| 형식 | PNG |
| 캡처 도구 | `Win + Shift + S` (윈도우 캡처 도구) → 영역 선택 |

캡처 후 파일명을 바꿔 `captures` 폴더에 넣으시면 됩니다.
**일부가 빠져도 매뉴얼은 생성됩니다** (그 자리에 「캡처 예정」 안내가 들어갑니다).
