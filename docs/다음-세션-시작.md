1. **메일 계정은 «화면에서» 고친다.** `.env` 를 손으로 고치지 말 것.
   [설정] → 「회사 공용 메일 계정 [관리자]」. 저장하면 즉시 반영되고
   의견 접수(:8086)도 1분 안에 따라온다. `.env` 는 비상용으로만 남아 있다.
   ⚠ **운영과 테스트는 DB 가 달라 각각 등록해야 한다.**

2. **메일 게이트는 «막지 않는다».** 로그인할 때 앱 비밀번호 등록을 권하지만
   「지금은 건너뛰고 들어가기」가 있다. 2026-08-29 에 막았다가 다섯 분이
   대시보드에 아예 못 들어온 일이 있었다 — 메일 때문에 본업을 막지 말 것.

3. **본인 계정 발송이 실패하면 공용 계정으로 다시 보내고 붉은 띠로 알린다.**
   보고를 버리면 KPI 에서 「누락」으로 잡히고서야 드러난다.

4. **`.ps1` 의 native 호출은 반드시 `Invoke-Native` 로 감쌀 것.**
   PowerShell 5.1 이 git·ssh·scp·docker 의 stderr 를 종료 오류로 둔갑시켜
   배포가 한복판에서 끊긴다(「전송은 됐고 빌드는 안 된」 상태가 남는다).

5. **다른 세션의 미커밋 변경이 있을 수 있다. `git add -A` 를 쓰지 말고
   파일을 하나씩 지정해 커밋할 것.**

6. **비밀번호는 사용자가 직접 넣는다.** 앱 비밀번호·계정 비밀번호를 대신
   입력하지 말 것.
